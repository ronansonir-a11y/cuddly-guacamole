# Ночной двор

3D-хоррор для Android. Ночь, двор панельных домов, кудрявый парень с сумкой вышел на охоту.

- **Ты** — кудрявый парень в очках с накрашенными губами (лицо взято с фото `IMG_20260629_154954.jpg`).
- **Он** — кудрявый с сумкой через плечо (фото `IMG_20261003_171056.jpg`).
- **Двор** — по скриншотам Яндекс Карт из репозитория: фасады домов, песок, площадки, деревья, машины.

Цель: найти **5 светящихся ключей**, открыть ворота на севере и добежать до подъезда дома №4.

## Скачать и установить

1. Открой раздел **Releases** этого репозитория и скачай `NochnoyDvor.apk` из релиза **latest**
   (либо во вкладке **Actions** открой последний успешный запуск «Build APK» и возьми артефакт `NochnoyDvor-apk`).
2. Разреши установку из неизвестных источников и открой файл.
3. Играть лучше в ландшафте, с наушниками.

Релиз пересобирается автоматически при каждом пуше (`.github/workflows/build-apk.yml`), сборка занимает несколько минут.
Нужен Android 5.0+ и поддержка OpenGL ES 2.0. Разрешения: только вибрация. Интернет не используется.

## Управление

| Что | Как |
| --- | --- |
| Ходьба | левая часть экрана — плавающий стик |
| Осмотр (камера) | правая часть экрана — водить пальцем |
| Бег | кнопка **БЕГ** (тратит силы, они восстанавливаются) |
| Фонарик | кнопка **СВЕТ** |
| Пауза | кнопка справа вверху или «Назад» |

## Как устроена охота

- Со светом враг замечает тебя издалека (около 18 м), без света — только вблизи (около 8 м); бег добавляет шума.
- Враг видит только то, что перед ним, и не видит сквозь постройки, будки, кусты и сараи — прячься за ними.
- Подобрать ключ — шумно: враг идёт проверить это место.
- Когда он замечает тебя, начинается погоня. Он быстрее ходьбы, но медленнее бега; с каждым ключом чуть быстрее.
- Если оторвался и потерял тебя из виду — он ищет, потом возвращается к патрулю. Долгая погоня выматывает и его: примерно через 12 секунд он замирает на несколько секунд.
- В паузах он любит постоять на одной ноге и смотреть на тебя. Это нормально. Наверное.

## Сборка из исходников

Нужны JDK 17 и Android SDK (платформа 34, build-tools 34.0.0).

```bash
./gradlew assembleDebug
# APK: app/build/outputs/apk/debug/app-debug.apk
```

Либо открой папку в Android Studio и запусти конфигурацию `app`.

## Текстуры и картинки

Все текстуры, иконки и экраны меню генерируются из фото и скриншотов в корне репозитория:

```bash
pip install pillow numpy opencv-python
python3 tools/make_assets.py
```

Результат кладётся в `app/src/main/assets/{tex,ui}` и `app/src/main/res/mipmap-*`.
Лица героя и врага вырезаются «яйцевидной» маской и ставятся на пластины-головы; фасады, песок и фон меню
получаются из скриншотов (с выравниванием освещения). Чтобы поменять героя или врага — замени фото и
поправь координаты кропа в `make_characters()`.

## Устройство проекта

```
app/src/main/java/ru/dvor/horror/
  MainActivity   экраны: меню, пауза, поимка, победа (обычные View поверх GLSurfaceView)
  Renderer       OpenGL ES 2.0: небо, двор, персонажи, ключи, свечения
  Models         герой и враг из примитивов + «лицо-пластина» с фото
  LevelBuilder   геометрия двора по батчам-текстурам; LevelProps — детали двора
  Level, Nav     коллайдеры, видимость, сетка A* для врага
  Game           правила, ключи, ворота, камера, свет и атмосфера
  Player, Enemy  движение героя; ИИ врага (патруль, взгляд, поиск, погоня)
  Audio          звук синтезируется при старте — аудиофайлов в проекте нет
  HudView        сенсорное управление и HUD
app/src/main/assets/shaders/   GLSL ES 1.0: мир (фонарик, точечные огни, туман), небо, спрайты
tools/make_assets.py           генерация текстур из фото и скриншотов
```

Логика игры (`Game`, `Enemy`, `Level`, `Nav`) не зависит от Android и гонялась в симуляции:
достижимость всех ключей и точек патруля, ИИ врага, прохождение ботами.

## Статус

Логика проверена симуляцией, а отрисовка — headless-рендером (те же шейдеры и вызовы OpenGL воспроизводились в WebGL).
На настоящем телефоне игра пока не запускалась, так что управление, производительность и звук ещё нужно проверить руками.
